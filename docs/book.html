1 Further explanation of AI policies for the course.

Course policies on the use of generative artificial intelligence (genAI, for example Claude or ChatGPT) are informed by these readings:

  • Bastani et al. 2025. Generative AI without guardrails can harm learning. PNAS
  • Carlson lab blog. The only reason you’ll ever need not to write with AI

Some examples of when genAI has worked well for me:

  • Generate a schedule for lectures (a tedious, rules-based task; easily verifiable answer)
  • Format a bibtex entry from information copied from a website (a tedious, rules-based task; easily verifiable answer)
  • Write code for a website in quarto (after the website is made I can update it using coding languages that I already know (90\(\%\) of the work). Without access to genAI I could not make the quatro files on my own next time I want to make a website using this approach)
  • Complete a short R coding project that I could have done on my own (I missed learning about some functions from a niche R package, but this will only set me back if I use that package again. This worked because I knew very clearly what I wanted and could verify the output.)

Some examples when genAI has not worked well for me:

  • Provide a short summary of a 5-10 page document that I wrote/Make an abstract given an outline. Could not improve even with guidance (did not emphasize the correct points of emphasis, took precise language and made it vague; overstated the significance of the work, with unnecessary grandiose language, which to a peer-reviewer suggests that you do not understand the significance of your work/what you are doing)
  • Julia code for non-linear optimization (it was a difficult coding project and my knowledge of Julia wasn’t good enough)
  • Students don’t have a good understanding of a topic, i.e., what makes good scientific writing, and they get genAI to do the task (write the report). (the student doesn’t know how to evaluate whether the output is good or not, they give this work to me to evaluate, which takes a long time. None of this is helping student learning much)
  • Students need to learn a skill (i.e., how to do a logistic regression), so I give them a project to help them learn it, but they get genAI to do it instead. (the student cannot answer questions about what they did, and would fail a subsequent evaluation such as an exam or thesis defence)
