# Wed Sept 16 - Samples and populations

## Samples and populations {#variables}

Populations are _all possible_ units and their associated observations of interest. Samples are a collection of observations from a population. The number of units in the sample is the sample size.

Variables, or measured quantities, are the characteristics that we record. Variables can be continuous, taking any value within a range, i.e., weight. Discrete variables can be ordered along the continuous scale (e.g., counts), and in some cases there are so many possibility that discrete variables can be treated essentially as continuous. For example, hypotheses that involve count data, when the values are large, are often tested with the same statistical tests as continuous data.

(Based on 2.1 of Quinn and Keough)
